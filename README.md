# Exercícios Práticos de JavaScript

Repositório dedicado ao estudo e à prática de JavaScript, com exercícios desenvolvidos para fortalecer a lógica de programação e os fundamentos da linguagem.

## Conteúdos praticados

- Variáveis e operadores
- Estruturas condicionais (`if` e `else`)
- Estruturas de repetição (`for`)
- Funções
- Estrutura `switch`
- Operações matemáticas
- Manipulação de dados de entrada

## Exercícios desenvolvidos

- Calculadora de IMC
- Comparação entre dois números
- Verificação de maioridade
- Verificação de aprovação por nota
- Par ou ímpar
- Número positivo ou negativo
- Dias da semana utilizando `switch`
- Exercícios com funções e estruturas de repetição

## Tecnologias utilizadas

- JavaScript

## Objetivo

Praticar conceitos fundamentais de programação por meio de exercícios simples, desenvolvendo o raciocínio lógico e a capacidade de resolver problemas.
